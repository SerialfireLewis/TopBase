# TopBase
A simple modpack for Modrinth. I will always use it in my modpacks <sub>unless not possible.</sub> mainly for shaders and animations. 
More mods may be added overtime and more dependencies may appear, so try not to use the wrong versions of minecraft.

# Installation
if you **somehow** don't know how to install the modpack, go to the [Modrinth Project](https://modrinth.com/modpack/topbasemp) and install it from there.

If for any reason you need to use another launcher I'll figure out how other launchers work because at the moment I *only* use NeoForge and Modrinth, try other launchers if you will but it is **not** recommended.
